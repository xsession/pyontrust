temp_sensor — 0x48 (TMP117)

High-accuracy digital temperature sensor. ±0.1°C from -20°C to +50°C.

AddrNameTypeR/WDoc
0x00temperatureint16readTemperature result. Raw × 0.0078125 = °C.
0x01configEXT__tmp117_config_tunread, writeConfiguration and control register.
0x02t_high_limitint16read, writeHigh-temperature alert threshold.
0x03t_low_limitint16read, writeLow-temperature alert threshold.
0x04eeprom_unlockuint16read, writeWrite 0x8000 to unlock EEPROM for writing.
0x05eeprom1uint16read, writeEEPROM user storage word 1.
0x06eeprom2uint16read, writeEEPROM user storage word 2.
0x07temperature_offsetint16read, writeUser temperature offset correction.
0x0fdevice_iduint16readDevice ID. Should read 0x0117.

eeprom — 0x50 (AT24C02)

256-byte I²C EEPROM for calibration data and board-specific configuration storage.

AddrNameTypeR/WDoc
0x00cal_headerEXT__cal_header_tstread, writeCalibration data header (magic + version + CRC).
0x08cal_databytesread, writeCalibration coefficients block.
0xf8board_infobytesread, writeBoard serial number and revision (8 bytes).

gpio_expander — 0x20 (PCF8574)

8-bit I/O expander for auxiliary digital I/O. Directly read or write the 8-bit port.

AddrNameTypeR/WDoc
—portEXT__gpio_expander_tunread, writeRead = input pin state. Write = output latch. Bits written as 1 are pulled high (quasi-bidirectional).

power_monitor — 0x40 (INA219)

Current and power monitor on the supply rail. Shunt resistor: 0.1 Ω.

AddrNameTypeR/WDoc
0x00configEXT__ina219_config_tunread, writeConfiguration register.
0x01shunt_voltageint16readShunt voltage measurement.
0x02bus_voltageEXT__ina219_bus_voltage_tunreadBus voltage measurement.
0x03poweruint16readPower = current × bus_voltage. LSB set by cal register.
0x04currentint16readMeasured current.
