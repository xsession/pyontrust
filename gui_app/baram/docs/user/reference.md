# Reference

## Entry points
- BaramFlow: `python -m baramFlow.main`
- BaramMesh: `python -m baramMesh.main`

## Useful scripts
- UI/resource generation: `python convertUi.py`
- Source archive release: `python tools/make_release.py --version <tag>`
- Binary build: `python tools/build_binaries.py`
- Binary release zip: `python tools/make_binary_release.py --version <tag>`
